# CRUX 误导抱石路线生成器

需要 Node.js 22.12 或更新版本。

```sh
npm install
npm run dev
```

访问终端显示的地址。

```sh
npm run typecheck
npm run build
docker compose up --build
```

Docker 地址为 http://127.0.0.1:8034 。

## 生成与合格证明

顶部生成器可指定：

- 岩点总数（18–32；18 是当前可证明蓝图的结构下限）
- `jug / edge / slope / step` 四类材质或抓握类型配额
- 起步四点接触组的脚点中心、终点 16 号点坐标
- 全程体力上限、随机种子和穷尽证明时限

点击“生成并做合格证明”后，生成器会：

1. 构造两条使用不同中段岩点组的完攀动作序列 A、B，并逐步调用挑战器的同一套 `evaluate` 规则验证。
2. 构造诱导前缀 `RH→08 → LF→17 → LH→21 → RH→22`，证明结束姿态落点支撑合格、仍有正剩余体力，且比起步位置更接近终点。
3. 以 `(LH, RH, LF, RF, energy)` 为状态执行穷尽 DFS，枚举每个状态下全部肢体 × 全部岩点的动作。搜索不是手点连通图：脚点占用、换脚顺序、触及、支撑和疲劳都会参与。
4. 输出访问状态数、检查动作数、诱导姿态的所有根换点及每个分支的关闭状态。只有证明完整、未超时、不存在预算内登顶分支时，路线才标记为 `qualified` 并发布；超时或发现逃生路线的草稿不能作为合格路线开始挑战。

合格路线会进入左侧路线列表并持久化到 `localStorage`。点击“直接开始挑战”后，挑战记录只根据实际落定动作分类为 A 方案、B 方案、混合/其他方案或“诱导成功”；不读取生成器中当前展开的是哪一张证据卡。
